# Casos de Teste — Segurança

Referências: OWASP API Security Top 10 (2023) e OWASP Top 10 (2021). O escopo não inclui autenticação, que está **ausente por decisão documentada** (ADR-013). A ausência é tratada como risco aceito no desafio e **impeditiva para produção** no resumo de qualidade.

Os testes são **não destrutivos**. Não há negação de serviço volumétrica: o consumo de recursos é verificado com requisições pontuais e abusivas, nunca com inundação.
